# Retail Sales SQL Assessment

## About the Project

This project focuses on analysing retail sales data using SQL. The aim is to compare sales across stores and regions and understand product returns during October 2026.

## Tools Used

- MySQL
- MySQL Workbench
- Visual Studio Code

## Project Files

- `database_setup.sql` – Database and table creation.
- `Insert Scripts/` – Data insertion scripts.
- `Retail_Assessment.sql` – SQL queries for the assessment.
- `Retail_Assessment_ER_Diagram.mwb` – Database ER diagram.
- `Retail SQL Assessment.docx` – Completed assessment worksheet.

## How to Run

1. Open MySQL Workbench and connect to MySQL.
2. Run `database_setup.sql`.
3. Execute the scripts inside the `Insert Scripts` folder.
4. Open `Retail_Assessment.sql`.
5. Select the `retail_assessment` database and execute the queries.
